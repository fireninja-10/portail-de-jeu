# Neon Dash

Petit jeu de plateforme arcade en `HTML/CSS/JS`, inspire de Geometry Dash.

## Lancer le jeu

Ouvre simplement [index.html](./index.html) dans un navigateur.

## Commandes

- `Espace`, `Fleche haut`, `W` ou clic/touch pour sauter
- `R` pour relancer une tentative

## Contenu

- deplacement automatique
- collisions avec pics, murs et trous
- pads de boost et orbes de saut
- interface responsive avec controles tactiles
