# Roulette Retro

Mini jeu de roulette en HTML/CSS/JS avec theme retro.

## Lancer le jeu

Ouvre `index.html` dans un navigateur moderne.

## Fonctionnalites

- Roue de roulette animee
- Jetons a mise multiple
- Paris sur numeros, couleurs, pair/impair, bas/haut, colonnes et douzaines
- Historique des tirages
- Annulation du dernier pari et effacement complet
